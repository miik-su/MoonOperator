# Community conduct

Treat contributors and users respectfully. Discuss code and evidence, welcome
questions, and accept correction. Harassment, threats, discriminatory abuse,
sexual harassment, doxxing and disclosure of another person's private information
are not acceptable in repository issues, pull requests or project discussions.

Maintainers may edit or remove harmful content, close discussions, warn people
or restrict participation according to severity and repetition. They should
explain decisions where doing so does not expose private information and should
not adjudicate a complaint in which they have a direct conflict of interest.

Report concerns to the repository owner using a private contact channel listed
on their GitHub profile. If none is available, request one without publishing
private details. Share only information needed to address the incident.
Maintainers should handle reports discreetly; absolute confidentiality cannot
be guaranteed. Vulnerabilities have a separate process in SECURITY.md.
